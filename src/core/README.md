# نواة المطابقة

مكتبة TypeScript نقية مستقلة عن Obsidian، تطبّق القسم ٣ والخوارزمية (ب) من [الدراسة](../../docs/study.md). بُنيت في المرحلة ١ وقِيست في [`docs/experiments/core-metrics.md`](../../docs/experiments/core-metrics.md).

قواعد هذا المجلد يفرضها `test/mobile-safety.test.ts`:

- دوال نقية فقط. **لا استيراد من `obsidian`** ولا من Node أو Electron، كي تُختبر خارج التطبيق وتعمل على الجوال.
- **لا نظرة خلفية** في التعابير النمطية: غير مدعومة على iOS قبل 16.4. افحص الحروف المجاورة برمجيًا.
- **لا خصائص Unicode** (`\p{…}`) في التعابير: قارن نطاقات صريحة.
- لا تبعيات تشغيل.

## الملفات

| الملف | الدور |
|---|---|
| `normalize.ts` | تطبيع الفئة (أ) مع خريطة مواضع إلى النص الأصلي وتسجيل حركات كل حرف؛ تقطيع الكلمات؛ تحويل نطاق مطبّع إلى نطاقه الأصلي بحركاته الأخيرة |
| `index.ts` | فهرس الأسماء: لكل عنوان واسم بديل نواة (بعد حذف «ال»)، وبقية الكلمات، وحركات العنوان، وخيارا الملاحظة `exactOnly` و`indefinite`؛ والعناوين المكررة |
| `protect.ts` | النطاقات المحمية من بيانات شبيهة بـ`CachedMetadata` ومن ماسح خفيف يمرّ على مراحل؛ الاقتباسات والجداول تُوسم؛ وجهات الروابط الموجودة |
| `match.ts` | `findMentions(doc, index, { sourcePath, cache })`: المرشحون بسلاسل السوابق، الحدود، الطبقات والأسباب والأعلام |

## الاستعمال

```ts
const index = buildIndex(allNotes, [activeNote.path]); // كل الملاحظات لاكتشاف المكرر؛ أسماء الهدف وحده تُفهرس
const mentions = findMentions(text, index, { sourcePath: file.path, cache });
// mention: { path, name, isAlias, start, end, surface, layer: 0|1|2, reasons: [{code, detail?}], flags }
```

`surface` هو الكلمة كاملة كما كُتبت بحركاتها وسوابقها، وهو النص الظاهر للرابط (القرار ٤).

## القواعد المنفَّذة

- **السوابق:** `(و|ف)? (ب|ك|ل)? (ال)?` مع «لل» (ل + ال)، و«لل» المدمجة لكلمة تبدأ بلام («للغة» = ل + اللغة)، وتطويل اختياري. السابقة على الكلمة الأولى فقط في العنوان المركّب، وبقية الكلمات حرفيًا بفاصل واحد مطبّع (لا مطابقة عبر سطر جديد).
- **الطبقات:** ٠ تطابق بعد الفئة (أ)؛ ١ سابقة، أو همزة أولى، أو نكرة لعنوان معرّف (بخيار `indefinite` فقط)، أو «ال» على عنوان نكرة؛ ٢ محتمل: سابقة مفردة على نواة من ثلاثة أحرف، لاحقة ضميرية (مع قلب ة إلى ت، على اسم من كلمة واحدة، بلا «ال»)، وعنوان مشكول مقابل نص غير مشكول.
- **الحماية:** لا نزع سابقة ولا لاحقة عن نواة من حرفين (إلا بمرساة «ال»)؛ `exactOnly` يُسقط كل ما ليس تطابقًا تامًا.
- **التشكيل المتعارض (القرار ١١):** إن شُكّل العنوان في حرف غير أخير، فالموضع المشكول بحركة مختلفة في الحرف نفسه يُسقط، وغير المشكول ينزل إلى ٢ بعلم `unvocalized`. حركة الحرف الأخير والتنوين والشدة لا تُقارن (إعراب أو رسم).
- **إضافة تصميمية غير واردة في الدراسة:** العنوان المعرّف مع لاحقة ضميرية («ذاكرته» لـ«الذاكرة») يُقبل طبقة ٢ دون خيار النكرة، لأن المضاف إلى ضمير معرّف بالإضافة.
- **الأعلام:** `quote` (اقتباس أو تنبيه)، `table`، `already-linked` (الملاحظة تربط الهدف بأي اسم من أسمائه)، `ambiguous-target` (ملاحظتان بالعنوان نفسه)، `unvocalized`.
- **ما لا يُفهرس:** أسماء بلا حروف، وأسماء لاتينية ملتصقة بترقيم ASCII («C++»). الرموز والترقيم المحيطة بالكلمات («📚 كتب»، «ما هو؟») تُقصّ من مفتاح البحث.

## حدود معروفة

- ألف تنوين النصب («زيدًا») تغيّر آخر الكلمة فلا تُلتقط؛ مرشّحة للفئة (ب) بعد المرحلة ٤.
- اللاتينية المفككة («e» + علامة مركّبة) لا تطابق المركّبة مسبقًا («é»)؛ لا يُطبَّق NFC على اللاتينية.
- الفاصل بين كلمات العنوان المركّب مسافة واحدة؛ «A-B» لا تطابق «A - B».
