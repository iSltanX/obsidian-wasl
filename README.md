## الفكرة

لوحة «الإشارات غير المربوطة» في Obsidian تبحث عن اسم الملاحظة حرفيًا، فتفوتها الإشارة العربية إذا جاءت بحركة أو تطويل أو سابقة. «وبالكتابةِ» و«للكتابة» و«الكتـابة» كلها تشير إلى ملاحظة «الكتابة»، والبحث الحرفي لا يلتقطها.

وصل تبحث عن عنوان الملاحظة المفتوحة وأسمائها البديلة في بقية الخزينة، بفهم للفروق الكتابية العربية. ثم تعرض كل موضع في سياقه مع سبب ظهوره، ولا تكتب الرابط إلا بعد موافقتك.

## المبادئ

- **مطابقة مقيّدة بعناوينك:** لا جذور ولا تجذيع ولا ذكاء اصطناعي. وصل تقارن بعناوين ملاحظاتك الموجودة فقط، مع قائمة مغلقة من السوابق.
- **نصك يبقى كما كتبته:** الرابط يحفظ الكلمة حرفيًا نصًا ظاهرًا، مثل `[[الكتابة|وبالكتابةِ]]`.
- **لا كتابة دون موافقة:** معاينة قبل الربط، وتراجع بعده، ولا ربط جماعي على الخزينة.
- **هادئة:** لا خطوط تحت الكلمات أثناء الكتابة؛ تعمل حين تفتح لوحتها فقط.
- **بلا تبعيات تشغيل،** ومكتوبة لتعمل على الهاتف. دعم iOS وأندرويد لا يُعلن قبل اختباره على أجهزة فعلية.

| انسان المدينة | الإنسان | نعم | همزة أولى محذوفة |

| أعجبني كتابه | الكتابة | لا | كتاب مع ضمير |

## التطوير

يحتاج Node 20 فأحدث.

```bash
npm install
npm test
npm run build
```

`npm run dev` يبني عند كل حفظ. قواعد الكود والاختبارات في [`CONTRIBUTING.md`](CONTRIBUTING.md).
